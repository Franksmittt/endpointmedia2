Color Usage Strategy:

- Cyan/teal accents draw attention to CTAs and important elements
- High contrast ensures excellent readability and conversion optimization
- Color psychology: Cyan/teal suggests technology, innovation, trust

TYPOGRAPHY:
-----------

Font Families:
- Primary (Body): System font stack - "Segoe UI", "Inter", -apple-system, 
  BlinkMacSystemFont, "Helvetica Neue", Arial, sans-serif
- Headings: Same system stack with increased weight and tracking

Font Weights:
- Body text: 400 (normal)
- Headings: 800 (extrabold) for H1, 700 (bold) for H2-H6
- CTAs: 700-800 (bold/extrabold)

Font Sizes (Responsive Clamp):
- H1: clamp(2.5rem, 1.5rem + 5vw, 4.5rem) - Massive, impactful headlines
- H2: clamp(2.25rem, 1.4rem + 4vw, 3.75rem) - Section headers
- H3: clamp(1.75rem, 1.2rem + 2.5vw, 2.5rem) - Subsection headers
- Body: 1rem (16px) base, scaling with lg (1.125rem), xl (1.25rem), 2xl (1.5rem)

Typography Characteristics:
- Tight letter-spacing (tracking-tight) on headings for modern look
- Relaxed line-height (leading-relaxed) for body text readability
- Bold, impactful headlines creating visual hierarchy
- System fonts for maximum performance (no font loading delays)

LAYOUT & SPACING:
-----------------

Container Strategy:
- max-width: 1280px (container mx-auto)
- Responsive padding: px-6 (24px) mobile, scaling on larger screens
- Consistent horizontal rhythm across all pages

Section Spacing:
- Standard section padding: py-24 (96px top/bottom)
- Hero sections: py-24 md:py-32 (96px mobile, 128px desktop)
- Consistent vertical rhythm for visual flow

Grid Systems:
- Responsive grid: grid-cols-1 md:grid-cols-2 lg:grid-cols-3
- Gap spacing: gap-8 (32px) standard, gap-12 (48px) for larger elements
- Flexbox for component-level layouts

Border Styles:
