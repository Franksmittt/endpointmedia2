================================================================================
                            EXECUTIVE SNAPSHOT
================================================================================

Endpoint Media is a Johannesburg-based technical web architecture, paid media,
local SEO, Answer Engine Optimization (AEO), and conversion systems agency.
The public marketing site is built with Next.js 16 App Router, React 19,
TypeScript, Tailwind CSS, Prisma/PostgreSQL, structured JSON-LD, static/ISR
delivery, edge proxy controls, and build-time Answer Engine assets.

The codebase operates as a machine-first acquisition platform:

- Human users receive fast, conversion-focused pages, hero audit tooling, and
  contact/store checkout flows.
- Googlebot/Bingbot receive deterministic full HTML and bot-specific headers.
- Answer engines receive llms.txt, llms-full.txt, clean JSON-LD @graph nodes,
  and layout-aware HtmlRAG chunk boundaries (data-chunk-boundary="true").
- Training scrapers, spoofed bots, recursive crawl loops, tracking-parameter
  variants, and known headless automation JA4 signatures are blocked or
  normalized at the edge before origin compute is wasted.

Recent product additions (June 2026):
- Enigma: Google Ads trading platform sign-in shell at /enigma (UI only;
  backend authentication pending).
- Homepage hero particle network animation (shared ParticleNetworkCanvas).
- Paystack-powered /store for technical audits and micro-services.
- Nine published case studies across automotive, finance, hospitality, retail,
  and professional services.

Enterprise SEO / AEO automation:

- scripts/seo/compile_llms.mjs (build-time llms.txt + llms-full.txt).
- gpt-tokenizer BPE ceiling (128k) for llms-full.txt.
- prebuild -> npm run b2a:compile.

Edge / crawler control (src/proxy.ts):
- Cryptographic bot verification (CIDR manifests + rDNS/forward DNS).
- Live-retrieval agent allowlist (OAI-SearchBot, PerplexityBot, etc.).
- Training scraper blocklist (GPTBot, CCBot, FacebookBot).
- JA4 TLS fingerprint blocking for headless automation signatures.
- Crawl traps (410 Gone), tracking param stripping (301), spell-check 404 recovery.
- Verified-bot immutable asset caching; unverified bot rate limiting.
- Optional serverless browser rendering for live-retrieval agents.
- PPR bot branching (blocking HTML shell for verified crawlers).

E-commerce / audits:
- /store hub with Paystack inline checkout (react-paystack, ZAR).
- Secure /api/webhook/paystack (HMAC SHA512 + Prisma StorePayment idempotency).
- Homepage hero "Run Deep Audit" -> /api/vicious-audit/run (Cheerio runtime checks;
  Playwright fingerprinting opt-in via AUDIT_ENABLE_PLAYWRIGHT=true).

AEO:
- Build-generated public/llms.txt and public/llms-full.txt
- data-chunk-boundary="true" on semantic sections
- Semantic tables for relational data
- Optional browser rendering for live-retrieval agents

Edge (src/proxy.ts):
Bot verification, scraper blocking, JA4 filtering, crawl traps, tracking param
normalization, spell-check redirects, verified-bot caching, rate limiting, PPR
bot branching, live-agent HTML rendering offload.
