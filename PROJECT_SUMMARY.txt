================================================================================
                            EXECUTIVE SNAPSHOT
================================================================================

Endpoint Media is a Johannesburg-based technical web architecture, paid media,
local SEO, and conversion systems agency. The site is built with Next.js 16 App
Router, React 19, TypeScript, Tailwind CSS, structured JSON-LD, static/ISR
delivery, edge proxy controls, and build-time Answer Engine Optimization assets.

The codebase now operates as a machine-first acquisition platform:

- Human users receive fast, conversion-focused pages and forms.
- Googlebot/Bingbot receive deterministic full HTML and bot-specific headers.
- Answer engines receive llms.txt, llms-full.txt, clean JSON-LD graph nodes, and
  layout-aware HtmlRAG chunk boundaries.
- Training scrapers, spoofed bots, recursive crawl loops, tracking-parameter
  variants, and known headless automation signatures are blocked or normalized
  at the edge before origin compute is wasted.

================================================================================
                         SEO, AEO, EDGE, AND BOT ARCHITECTURE
================================================================================

Schema:
- secureJsonLD() sanitizes JSON-LD payloads.
- Homepage emits one @graph script only.
- Root graph nodes are centralized in src/lib/seo.ts.
- Homepage graph includes Organization, LocalBusiness, WebSite, Person, WebPage,
  and FAQPage nodes.
- All core IDs use absolute canonical www endpointmedia.co.za fragments.

Metadata:
- buildMetadata() creates canonical, Open Graph, Twitter, and language alternate
  values for pages.
- Canonical strategy: always https://www.endpointmedia.co.za, trailingSlash false.

Answer Engine Optimization:
- Generated public/llms.txt and public/llms-full.txt.
- HtmlRAG chunk boundaries on homepage and blog prose components.
- Semantic tables for relational metric/pricing data.
- Optional serverless browser-rendering offload for live-retrieval agents.

Edge proxy:
- File: src/proxy.ts.
- Adds crawler verification, scraper blocking, JA4 fingerprint filtering,
  tracking-parameter normalization, crawl traps, spell-check redirects, verified
  bot cache policy, and live-retrieval browser-rendering offload.

Security / anti-abuse:
- Blocks known training scrapers.
- Blocks spoofed Google/Bing bots that fail manifest/rDNS verification.
- Blocks known headless JA4 fingerprints.
- Rate-limits unverified bot-like static asset traffic.
- Returns 410 for recursive trap patterns.
