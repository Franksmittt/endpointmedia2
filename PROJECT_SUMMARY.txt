FORMS & LEAD CAPTURE:
---------------------
AuditForm (src/components/sections/AuditForm.tsx):
- Client component, POST /api/contact
- Fields: name, business, email, phone, source
- Off-screen `website` honeypot (structural, not opacity-only)
- aria-live status feedback, trackFreeAudit() on success

ContactForm (src/app/contact/ContactForm.tsx):
- Dynamically imported on /contact (code-split)
- Same API route, Resend delivery
- trackFormSubmission() analytics hook

Contact API (src/app/api/contact/route.ts) — P0 HARDENED:
- Content-Type: application/json required (415)
- Rate limit: 5 POSTs/min/IP (src/lib/rate-limit.ts, in-memory)
- Payload caps: name 120, message 5000, email 254, phone 32 chars
- sanitizeHeader() strips \\r\\n\\t from name/source before email subject
- Honeypot: silent 200 if `website` OR legacy `honeypot` filled
- Resend email to CONTACT_TO_EMAIL (env)

IndexNow API (src/app/api/indexnow/route.ts):
- Bearer auth (INDEXNOW_SECRET or CRON_SECRET)
- Submits sitemap URLs to Bing/Yandex IndexNow
